α

SnapMap is currently in alpha.

We're still actively building and refining it. That's why SnapMap is a web app right now: we can ship improvements faster, fix bugs quickly, and shape the product around real feedback before locking it into an app-store release. Expect occasional rough edges and features that evolve as the app grows.

Want it to feel like an app on iPhone? Open SnapMap in Safari, tap Share, then choose Add to Home Screen.
