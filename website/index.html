Why SnapMap is a web app right now.

SnapMap is still in active development. It runs as a web app while features, stability, and performance are being refined so updates can ship quickly without waiting on app-store releases. Expect occasional bugs, unfinished areas, and changes as the app evolves.

Want it to feel more like an app on iPhone? Open SnapMap in Safari, tap Share, then choose Add to Home Screen. You’ll get a home-screen icon and a more app-like launch experience.
